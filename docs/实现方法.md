## 2. 数据准备

### 2.1 建筑Shapefile要求

建筑Shapefile必须包含以下字段：

| 字段名 | 类型 | 必需 | 描述 |
|-------|------|------|------|
| `id` | Integer | ✓ | 建筑唯一标识符 |
| `height` | Float | ✓ | 建筑高度（米） |
| `albedo` | Float | 推荐 | 表面反射率（0-1） |
| `hwratio` | Float | 推荐 | 高宽比 |
| `area` | Float | ✓ | 占地面积（m²） |
| `perimeter` | Float | 聚类用 | 周长（米） |
| `orientatio` | Float | 聚类用 | 主轴朝向（度） |
| `elongation` | Float | 聚类用 | 伸长度 |
| `concavity` | Float | 聚类用 | 凹度 |
| `circularit` | Float | 聚类用 | 圆度 |
| `rectangula` | Float | 聚类用 | 矩形度 |
| `lcz` | Integer | 训练用 | 真实LCZ标签（1-9） |

**注意**：字段名受Shapefile 10字符限制，部分字段名为缩写。

### 2.2 区县Shapefile要求

| 字段名 | 类型 | 必需 | 描述 |
|-------|------|------|------|
| `FID` 或 `fid` | Integer | ✓ | 区县唯一标识符 |
| `geometry` | Polygon | ✓ | 区县边界多边形 |

### 2.3 坐标系要求

- 建筑和区县Shapefile必须使用相同的投影坐标系
- 推荐使用UTM投影（如EPSG:32650）
- 不支持地理坐标系（WGS84经纬度）

### 2.4 数据验证脚本

```python
import geopandas as gpd

def validate_building_data(building_path):
    """验证建筑数据完整性"""
    buildings = gpd.read_file(building_path)
    
    # 检查必需字段
    required_fields = ['id', 'height', 'area']
    missing = [f for f in required_fields if f not in buildings.columns]
    if missing:
        print(f"❌ 缺少必需字段: {missing}")
        return False
    
    # 检查GAT特征字段
    gat_fields = ['albedo', 'hwratio']
    missing_gat = [f for f in gat_fields if f not in buildings.columns]
    if missing_gat:
        print(f"⚠️ 缺少推荐GAT字段: {missing_gat}")
    
    # 检查聚类特征字段
    clustering_fields = ['perimeter', 'orientatio', 'elongation', 
                         'concavity', 'circularit', 'rectangula']
    missing_cluster = [f for f in clustering_fields if f not in buildings.columns]
    if missing_cluster:
        print(f"⚠️ 缺少聚类字段: {missing_cluster}")
    
    # 检查坐标系
    if buildings.crs is None:
        print("❌ 未定义坐标系")
        return False
    if buildings.crs.is_geographic:
        print(f"❌ 请使用投影坐标系，当前为地理坐标系: {buildings.crs}")
        return False
    
    print(f"✓ 数据验证通过")
    print(f"  建筑数量: {len(buildings)}")
    print(f"  坐标系: {buildings.crs}")
    return True

# 使用
validate_building_data('/path/to/buildings.shp')
```

## 3. Extractor使用

### 3.1 基本命令

```bash
# 生成维诺图和邻接矩阵
python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp
```

### 3.2 命令行参数

| 参数 | 描述 | 默认值 |
|------|------|--------|
| `--generate-voronoi-diagram` | 生成维诺图模式 | - |
| `--generate-raster-for-training` | 生成栅格模式 | - |
| `--district-path` | 区县Shapefile路径 | .env中的DISTRICT |
| `--visualize` | 启用可视化 | False |
| `--viz-interval` | 可视化间隔（迭代次数） | 1 |
| `--debug-voronoi` | 调试模式（按空格步进） | False |
| `--debug-adjacency` | 导出邻接矩阵CSV | False |
| `--use-mpi` | 启用MPI并行 | False |
| `--enable-large-district-mode` | 大区县分块处理 | False |

### 3.3 MPI并行处理

```bash
# 使用8个进程并行处理
mpirun -n 8 python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp \
    --use-mpi

# LSF集群提交
bsub -n 16 -R "span[hosts=1]" \
    mpirun python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp \
    --use-mpi
```

### 3.4 可视化调试

```bash
# 开启可视化，每5次迭代显示一次
python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp \
    --visualize \
    --viz-interval 5

# 调试模式：按空格逐步执行
python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp \
    --visualize \
    --debug-voronoi
```

**可视化控制：**
- `空格`：下一步（调试模式）
- `q`：退出
- `p`：暂停/继续（非调试模式）

### 3.6 大区县处理

对于面积超大的区县（导致栅格超过内存限制），启用分块处理：

```bash
python -m src.extractor \
    --generate-voronoi-diagram \
    --district-path /path/to/districts.shp \
    --enable-large-district-mode
```

**分块处理参数**（在 `src/extractor/utils/config.py` 中配置）：
- `max_chunk_size`：单块最大像素数（默认5000x5000）
- `chunk_overlap`：块间重叠像素（默认100）

## 4. GAT训练

### 4.1 训练模式

| 模式 | 描述 | 用途 |
|------|------|------|
| `cv` | K折交叉验证 | 超参数调优、模型评估 |
| `final` | 全量数据训练 | 生成最终部署模型 |

### 4.2 交叉验证训练

```bash
python -m src.gat --train \
    --adjacency-dir output/voronoi \
    --sample-buildings /path/to/buildings.shp \
    --sample-districts /path/to/districts.shp \
    --output-root-dir output/gat \
    --config src/gat/training_config.yaml \
    --model-identifier my_model_v1 \
    --mode cv
```

### 4.3 最终模型训练

```bash
python -m src.gat --train \
    --adjacency-dir output/voronoi \
    --sample-buildings /path/to/buildings.shp \
    --sample-districts /path/to/districts.shp \
    --output-root-dir output/gat \
    --config src/gat/training_config.yaml \
    --model-identifier final_v1 \
    --mode final
```

### 4.4 训练参数

| 参数 | 描述 | 示例 |
|------|------|------|
| `--adjacency-dir` | 邻接矩阵目录 | output/voronoi |
| `--sample-buildings` | 训练建筑Shapefile | data/buildings.shp |
| `--sample-districts` | 训练区县Shapefile | data/districts.shp |
| `--output-root-dir` | 输出根目录 | output/gat |
| `--config` | 配置文件路径 | src/gat/training_config.yaml |
| `--model-identifier` | 模型标识符 | v1, final |
| `--mode` | 训练模式 | cv, final |
| `--resume` | 恢复训练检查点 | checkpoints/epoch_100.pth |
| `--total-buildings` | 全量建筑（用于scaler） | data/all_buildings.shp |

### 4.5 MPI并行交叉验证

```bash
python -m src.gat --inference \
    --model-path output/gat/models/final_model.pth \
```

## 6. 配置参数参考

### 6.1 模型参数 (`model`)

| 参数 | 默认值 | 范围 | 描述 |
|------|--------|------|------|
| `hidden_dim` | 32 | 16-128 | 隐藏层维度 |
| `num_layers` | 3 | 2-4 | GAT层数 |
| `num_heads` | 8 | 4-16 | 注意力头数 |
| `dropout` | 0.6 | 0.3-0.7 | Dropout比例 |
| `edge_dim` | 1 | - | 边特征维度 |
| `use_edge_features` | false | - | 使用边特征 |
| `add_self_loops` | true | - | 添加自环 |
| `negative_slope` | 0.2 | 0.1-0.3 | LeakyReLU负斜率 |

### 6.2 训练参数 (`training`)

| 参数 | 默认值 | 范围 | 描述 |
|------|--------|------|------|
| `epochs` | 2000 | 500-5000 | 最大训练轮数 |
| `lr` | 0.005 | 0.0001-0.01 | 学习率 |
| `weight_decay` | 0.0002 | 0-0.001 | 权重衰减 |
| `batch_size` | 64 | 32-256 | 批次大小 |
| `k_fold` | 5 | 3-10 | 交叉验证折数 |
| `patience` | 120 | 20-200 | 早停耐心值 |
| `min_delta` | 0.001 | 0.0001-0.01 | 早停最小改进 |
| `val_interval` | 2 | 1-10 | 验证间隔 |
| `lambda_smooth` | 0.3 | 0.1-1.0 | 平滑损失权重 |
| `smooth_temperature` | 0.05 | 0.01-0.2 | 平滑损失温度 |
| `node_threshold` | 2000 | 1000-5000 | 小批量采样阈值 |
| `num_neighbors` | [15, 10] | - | 邻居采样数 |

### 6.3 谱聚类参数 (`spectral_clustering`)

| 参数 | 默认值 | 范围 | 描述 |
|------|--------|------|------|
| `embedding_weight` | 0.6 | 0.3-0.8 | 嵌入相似度权重 |
| `feature_weight` | 0.2 | 0.1-0.4 | 特征相似度权重 |
| `distance_weight` | 0.2 | 0.1-0.4 | 距离亲和度权重 |
| `distance_scale` | 20.0 | 10-100 | 距离衰减尺度（米） |
| `use_constrained_clustering` | true | - | 约束聚类 |
| `clustering_linkage` | ward | ward/average/complete | 链接方法 |
| `enforce_connectivity_post` | true | - | 后处理连通性 |
| `min_cluster_size` | 5 | 3-20 | 最小聚类大小 |
| `min_component_size` | 10 | 5-30 | 最小分量大小 |
| `oversample_factor` | 0.8 | 0.5-2.0 | 聚类数过采样 |
| `use_confidence_weighted_voting` | true | - | 置信度加权投票 |

### 6.4 相似度损失参数 (`similarity_loss`)

| 参数 | 默认值 | 范围 | 描述 |
|------|--------|------|------|
| `enabled` | true | - | 启用相似度损失 |
| `temperature` | 0.05 | 0.02-0.3 | 软标签温度 |

### 6.5 调优建议

**场景1：小数据集（<5000建筑）**
```yaml
model:
  hidden_dim: 32
  num_layers: 2
  dropout: 0.7
training:
  epochs: 3000
  patience: 200
  lr: 0.001
```

**场景2：大数据集（>50000建筑）**
```yaml

  hidden_dim: 64
  num_layers: 3
  dropout: 0.5

  epochs: 1000
  patience: 50
  lr: 0.005
  node_threshold: 3000
```

**场景3：强调空间连续性**
```yaml

  embedding_weight: 0.4
  feature_weight: 0.3
  distance_weight: 0.3
  min_cluster_size: 10
```

### 7.2 数据问题

**问题：找不到建筑**
```
WARNING - No buildings found for district 123
```
**排查：**
1. 检查坐标系是否一致
2. 检查建筑和区县是否有空间交集
3. 检查ID字段是否正确

```python
# 诊断脚本
import geopandas as gpd

buildings = gpd.read_file('buildings.shp')
districts = gpd.read_file('districts.shp')

print(f"建筑CRS: {buildings.crs}")
print(f"区县CRS: {districts.crs}")

# 检查空间交集
for idx, district in districts.iterrows():
    count = buildings[buildings.intersects(district.geometry)].shape[0]
    print(f"区县 {idx}: {count} 建筑")
```

**问题：邻接矩阵为空**
```
WARNING - Adjacency matrix empty
```
**排查：**
1. 检查维诺图是否正确生成
2. 检查建筑ID是否匹配

### 7.3 训练问题

**问题：CUDA内存不足**
```
RuntimeError: CUDA out of memory
```
**解决：**
1. 减小 `batch_size`
2. 减小 `hidden_dim`
3. 设置 `node_threshold` 启用小批量采样
4. 使用 `--device cpu`

**问题：损失不下降**
**排查：**
1. 检查学习率是否合适
2. 检查数据标签分布
3. 尝试禁用相似度损失

```yaml
# 诊断配置
similarity_loss:
  enabled: false
training:
  lr: 0.001
  lambda_smooth: 0
```

**问题：过拟合（训练准确率高，验证低）**
**解决：**
1. 增加 `dropout`
2. 增加 `weight_decay`
3. 减小 `hidden_dim`
4. 启用早停（减小 `patience`）

### 7.4 推理问题

**问题：模型加载失败**
```
KeyError: 'model_state_dict'
```
**解决：**
检查检查点格式，可能是旧版本格式：
```python
# 转换旧格式
checkpoint = torch.load('old_model.pth')
```
