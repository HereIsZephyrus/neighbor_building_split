## 1. 问题背景

### 1.1 本地气候区（LCZ）分类

本地气候区（Local Climate Zone, LCZ）是一套标准化的城市形态分类体系，将城市区域划分为17种类别，其中LCZ1-9为建成区类型：

| LCZ | 名称 | 特征 |
|-----|------|------|
| LCZ1 | 紧凑高层 | 高密度、高层建筑 |
| LCZ2 | 紧凑中层 | 高密度、中层建筑 |
| LCZ3 | 紧凑低层 | 高密度、低层建筑 |
| LCZ4 | 开敞高层 | 低密度、高层建筑 |
| LCZ5 | 开敞中层 | 低密度、中层建筑 |
| LCZ6 | 开敞低层 | 低密度、低层建筑 |
| LCZ7 | 轻质低层 | 轻质材料、低层建筑 |
| LCZ8 | 大跨度低层 | 大型仓储、工业建筑 |
| LCZ9 | 稀疏建筑 | 稀疏分布的建筑 |

### 1.2 城市建筑分类的挑战

在城市规划和建筑分析中，建筑类型往往表现出**空间聚集性**：

- 同一街区的建筑倾向于属于同一类别
- 类别边界通常是清晰的区域界限，而非随机分布
- 单个建筑的预测可能存在噪声，但邻近相似建筑应该有相同的标签

### 1.3 传统方法的局限

**纯分类方法**（如单纯使用GCN/GAT）：
- 仅关注判别性，可能产生"孤立点"错误
- 难以显式利用空间形态相似性
- 在类别边界处容易产生不确定性

**纯聚类方法**（如K-means、谱聚类）：
- 缺乏有监督的判别能力
- 无法利用深度学习的强大特征学习能力
- 难以处理复杂的非线性模式

## 2. 核心思想：两阶段分类策略

### 2.1 策略概述

本算法采用**两阶段分类+空间平滑**策略：

```
┌─────────────────────────────────────────────────────────────────────┐
│                     第一阶段：GAT图注意力网络分类                      │
├─────────────────────────────────────────────────────────────────────┤
│  输入：判别性特征（height, albedo, hwratio, density）                 │
│  目标："这是什么类型的建筑？"                                         │
│  输出：每个建筑的类别预测 + 预测置信度                                 │
└─────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌─────────────────────────────────────────────────────────────────────┐
│                     第二阶段：谱聚类空间平滑                          │
├─────────────────────────────────────────────────────────────────────┤
│  输入：形态学特征（area, perimeter, orientation, shape）             │
│  目标："哪些建筑应该归为一组？"                                       │
│  方法：置信度加权的多数投票                                           │
│  输出：空间连续、一致的最终标签                                       │
└─────────────────────────────────────────────────────────────────────┘
```

### 2.2 两阶段的互补性

| 阶段 | 关注点 | 特征类型 | 输出 |
|------|--------|---------|------|
| GAT分类 | 判别性：建筑是什么类型 | 高度、反射率、高宽比 | 类别预测 + 置信度 |
| 谱聚类 | 分组性：哪些建筑相似 | 面积、形状、朝向 | 空间连续的标签 |

这种互补设计使得：
- GAT可以专注于学习类别判别边界
- 谱聚类可以专注于发现空间聚集模式
- 两者结合产生既准确又空间连续的结果

## 3. 任务解耦原理

### 3.1 为什么要解耦？

传统端到端模型试图同时优化两个可能冲突的目标：
1. **分类准确**：预测正确的类别
2. **空间平滑**：相邻建筑标签一致

这两个目标在某些情况下会冲突：
- 类别边界处：准确性要求正确区分，平滑性要求一致
- 异常点处：准确性要求正确识别，平滑性可能导致被"平均化"

### 3.2 解耦的好处

```
传统方法：                        我们的方法：
┌─────────────────┐              ┌─────────────────┐
│   单一模型       │              │   GAT模型       │
│ 分类 + 平滑     │              │ 专注于分类      │
│ （目标冲突）     │              └────────┬────────┘
└─────────────────┘                       │
        ↓                                 ▼
    综合性能受限                  ┌─────────────────┐
                                 │   谱聚类        │
                                 │ 专注于平滑      │
                                 └────────┬────────┘
                                          │
                                          ▼
                                     最优综合性能
```

**优势：**
1. 各司其职，避免单一模型同时优化冲突目标
2. 可以分别针对性地调优
3. 提高整体性能和可解释性
4. 便于分析每个阶段的贡献

## 4. 空间自相关理论

### 4.1 Tobler第一定律

> "Everything is related to everything else, but near things are more related than distant things."
> 
> "所有事物都相互关联，但近的事物比远的事物关联更强。"
> — Waldo Tobler, 1970

这是地理学的基本定律，也是我们算法的理论基础。

### 4.2 在建筑分类中的应用

城市建筑表现出强烈的空间自相关性：

1. **居住区聚集**：住宅建筑倾向于成片分布
2. **商业集中**：商业建筑沿街道或商圈聚集
3. **工业园区**：工业建筑通常集中在特定区域
4. **渐变过渡**：不同类型区域之间存在过渡带

### 4.3 利用空间自相关

我们的算法通过以下方式利用空间自相关：

```python
# 1. 维诺图构建邻接关系
# 基于空间接近性定义"邻居"
adjacency = voronoi_adjacency(buildings)

# 2. 距离衰减的空间约束
# 越近的建筑，约束越强
distance_affinity = exp(-distance / scale)

# 3. 邻域内多数投票
# 相邻相似建筑统一标签
cluster_label = weighted_majority_vote(neighbors)
```

## 5. 双特征集策略

### 5.1 设计原理

**核心洞察**：分类和分组需要不同类型的特征。

| 任务 | 目标 | 最佳特征 | 示例 |
|------|------|---------|------|
| 分类 | 区分类别 | 判别性特征 | 高度区分高层/低层 |
| 分组 | 找相似建筑 | 形态学特征 | 形状相似=可能同类 |

### 5.2 GAT特征（判别性）

选择对类别区分最有效的特征：

```yaml
gat_features:
  - height      # 建筑高度：区分高层/中层/低层
  - albedo      # 反射率：区分建筑材料类型
  - hwratio     # 高宽比：区分建筑形态
  - area        # 面积：区分大型/小型建筑
  # 动态添加：
  - degree      # 邻居数量：反映建筑密度
  - neighdis    # 邻居距离：反映空间布局
```

**为什么选择这些特征？**
- `height`：LCZ分类的核心指标，直接对应高/中/低层
- `albedo`：反映建筑材料，工业建筑通常反射率不同
- `hwratio`：高层建筑通常高宽比大，低层相反
- `density`（通过degree体现）：紧凑型LCZ密度高

### 5.3 聚类特征（形态学）

选择描述建筑形态和空间关系的特征：

```yaml
clustering_features:
  - height         # 高度（与GAT共享）
  - area           # 面积
  - perimeter      # 周长
  - orientatio     # 主轴朝向
  - elongation     # 伸长度
  - concavity      # 凹度
  - circularit     # 圆度
  - rectangula     # 矩形度
  - fractality     # 分形维数
```

**为什么选择这些特征？**
- 形态相似的建筑更可能是同一开发批次
- 相同规划区域内建筑形态通常一致
- 这些特征对分类不敏感，但对分组很有效

### 5.4 特征分离的效果

```
示例场景：一片住宅区中有一栋商业建筑

GAT分类结果：
  - 住宅建筑 → 预测为LCZ6（开敞低层），置信度0.85
  - 商业建筑 → 预测为LCZ8（大跨度低层），置信度0.90

如果使用相同特征聚类：
  - 商业建筑可能被"平滑"为LCZ6 ❌

使用形态学特征聚类：
  - 商业建筑形态独特（面积大、形状不规则）
  - 聚类为独立cluster
  - 保持正确的LCZ8标签 ✓
```

## 6. 置信度加权投票机制

### 6.1 传统多数投票的问题

简单多数投票：每个建筑一票，票数最多的类别获胜。

**问题示例：**
```
聚类中有5个建筑：
  - 3个预测为类别A（GAT置信度：0.40, 0.35, 0.38）
  - 2个预测为类别B（GAT置信度：0.95, 0.92）

简单投票：A获胜（3票 > 2票）
但实际上：A的预测很不确定，B的预测非常确定
正确答案应该是B！
```

### 6.2 置信度加权投票

我们的方案：高置信度的预测拥有更大的投票权重。

**数学公式：**
```
label_weight[l] = Σ confidence[i]  for all i with label=l
final_label = argmax(label_weight)
```

**同一示例：**
```
类别A权重 = 0.40 + 0.35 + 0.38 = 1.13
类别B权重 = 0.95 + 0.92 = 1.87

结果：B获胜 ✓（1.87 > 1.13）
```

### 6.3 置信度计算

置信度定义为softmax概率的最大值：

```python
def compute_confidence(logits):
    """
    计算GAT预测的置信度
    
    Args:
        logits: GAT输出的分类logits (N, num_classes)
    
    Returns:
        confidence: 每个预测的置信度 (N,)，范围[0,1]
    """
    probs = softmax(logits, axis=1)
    confidence = max(probs, axis=1)
    return confidence
```

**置信度的含义：**
- 高置信度（>0.8）：GAT非常确定其预测
- 中等置信度（0.5-0.8）：GAT有一定把握
- 低置信度（<0.5）：GAT不确定，可能处于类别边界

### 6.4 为什么有效？

1. **高置信度的正确预测主导投票**
2. **低置信度的错误预测影响较小**
3. **自动适应GAT的不确定性**
4. **在类别边界处更鲁棒**

## 7. 亲和矩阵构建原理

### 7.1 什么是亲和矩阵？

亲和矩阵（Affinity Matrix）描述节点之间的相似程度，是谱聚类的输入。

```
Affinity[i,j] = 建筑i和建筑j的相似度，范围[0,1]
  - 1.0：完全相似
  - 0.0：完全不相似或不相邻
```

### 7.2 三种相似度来源

我们的亲和矩阵综合三种信息：

```
Affinity = w_emb × Embedding_Similarity 
         + w_feat × Feature_Similarity 
         + w_dist × Distance_Affinity

默认权重：w_emb=0.6, w_feat=0.2, w_dist=0.2
```

#### 7.2.1 嵌入相似度（Embedding Similarity）

**来源**：GAT学习到的节点嵌入向量

**计算**：余弦相似度
```python
embedding_sim = cosine_similarity(embeddings)
# 归一化到[0,1]
embedding_sim = (embedding_sim + 1) / 2
```

**含义**：GAT认为相似的建筑

**权重设计（0.6）**：
- EdgeConv嵌入高度信息化，包含了空间距离信息
- 适当提高权重以利用GAT的判别能力

#### 7.2.2 特征相似度（Feature Similarity）

**来源**：形态学聚类特征

**计算**：余弦相似度
```python
feature_sim = cosine_similarity(clustering_features)
# 归一化到[0,1]
feature_sim = (feature_sim + 1) / 2
```

**含义**：形态相似的建筑

**权重设计（0.2）**：
- 作为嵌入的补充信息
- 捕捉GAT可能忽略的形态相似性

#### 7.2.3 距离亲和度（Distance Affinity）

**来源**：建筑间的空间距离

**计算**：指数衰减
```python
distance_affinity = exp(-distance / scale)
# scale控制衰减速度，默认20米
```

**含义**：空间上接近的建筑

**权重设计（0.2）**：
- 作为空间约束，防止远距离建筑聚类
- 保持适度，避免过度强制邻近性

### 7.3 权重选择的考虑

| 场景 | 推荐权重 | 理由 |
|------|---------|------|
| 高置信度GAT | emb=0.7, feat=0.1, dist=0.2 | 信任GAT判断 |
| 复杂边界区域 | emb=0.4, feat=0.4, dist=0.2 | 均衡考虑 |
| 强空间约束 | emb=0.5, feat=0.2, dist=0.3 | 强调空间邻近 |

### 7.4 空间约束的实现

为确保聚类结果空间连续，我们施加额外约束：

```python
# 只有空间相邻的建筑才能有非零亲和度
adjacency_mask = adjacency_matrix > 0
affinity[~adjacency_mask] = 0

# 对称化（谱聚类要求）
affinity = (affinity + affinity.T) / 2
```

## 8. 理论基础总结

### 8.1 与条件随机场（CRF）的类比

我们的方法类似于CRF的能量最小化：

```
E(labels) = Σ_i Unary(y_i) + Σ_(i,j) Pairwise(y_i, y_j)
            ↑                 ↑
        GAT分类            谱聚类平滑
```

- **Unary term**：GAT给出的单节点预测（带置信度）
- **Pairwise term**：亲和矩阵编码的节点间关系

### 8.2 集成学习视角

两阶段方法也可以看作一种**空间集成学习**：

1. **基学习器**：GAT提供初步预测
2. **集成策略**：谱聚类通过空间投票进行修正
3. **权重机制**：置信度作为样本重要性

**优势**：
- 结合深度学习和传统机器学习的优点
- GAT的非线性表达 + 谱聚类的空间连续性
- 鲁棒性强于单一方法

### 8.3 图信号处理视角

从图信号处理角度：
- **GAT**：学习图上的非线性滤波器
- **谱聚类**：基于图拉普拉斯的频谱分解
- **亲和矩阵**：定义图信号的平滑性

### 8.4 关键贡献总结

| 贡献 | 描述 | 效果 |
|------|------|------|
| 任务解耦 | 分类和空间平滑作为独立任务 | 避免目标冲突 |
| 双特征集 | 判别性特征用于分类，形态特征用于分组 | 任务专注 |
| 置信度加权 | 高置信度预测主导，低置信度错误被抑制 | 提高鲁棒性 |
| 空间约束 | 只有相邻建筑才能聚类 | 保证连续性 |
