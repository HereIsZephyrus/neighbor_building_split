### 2.2 维诺图生成算法

#### 2.2.1 形态学膨胀方法

我们采用形态学膨胀（Morphological Dilation）生成维诺图分区，而非传统的几何维诺图算法。

**算法流程：**

```python
def generate_voronoi_from_raster(building_raster, district_mask):
    """
    基于形态学膨胀的维诺图生成
    
    步骤：
    1. 初始化：每个建筑像素标记为其建筑ID
    2. 迭代膨胀：每轮向相邻未标记像素扩展
    3. 冲突处理：当两个建筑同时到达某像素时，保留先到者
    4. 终止条件：所有区县内像素都被标记
    """
    voronoi = building_raster.copy()
    structure = generate_binary_structure(2, 2)  # 8连通
    
    for iteration in range(max_iterations):
        unlabeled_mask = (voronoi == 0) & (district_mask == 1)
        if not unlabeled_mask.any():
            break
            
        for label in unique_labels:
            label_mask = (voronoi == label)
            dilated = binary_dilation(label_mask, structure)
            new_pixels = dilated & unlabeled_mask
            voronoi[new_pixels] = label
            
    return voronoi
```

**设计考虑：**

| 方案 | 优点 | 缺点 | 选择 |
|------|------|------|------|
| 几何维诺图 | 数学精确 | 不规则建筑难处理 | ✗ |
| 形态学膨胀 | 适应任意形状 | 近似结果 | ✓ |

### 2.3 邻接矩阵计算

#### 2.3.1 邻接关系定义

两个建筑被认为是"邻接"的，当且仅当它们的维诺图多边形共享边界。

```python
def find_adjacent_voronoi_regions(voronoi_gdf):
    """
    基于空间索引的邻接关系检测
    """
    adjacent_pairs = []
    sindex = voronoi_gdf.sindex
    
    for _, row in voronoi_gdf.iterrows():
        geom = row.geometry
        # 使用空间索引快速筛选候选邻居
        candidates = list(sindex.intersection(geom.bounds))
        
        for candidate in candidates:
            neighbor = voronoi_gdf.iloc[candidate]
            if geom.touches(neighbor.geometry) or \
               (geom.intersects(neighbor.geometry) and 
                geom.intersection(neighbor.geometry).length > 0):
                adjacent_pairs.append((row.building_id, neighbor.building_id))
                
    return adjacent_pairs
```

#### 2.3.2 距离矩阵

邻接矩阵存储建筑间的实际距离（米），而非简单的0/1：

```python
def create_adjacency_matrix(voronoi_gdf, buildings_gdf):
    """
    创建带距离值的邻接矩阵
    
    Matrix[i,j] = 
        0      : 不相邻
        >0     : 建筑i和j之间的最短距离（米）
    """
    for bid_i, bid_j in adjacent_pairs:
        geom_i = buildings_gdf.loc[bid_i, 'geometry']
        geom_j = buildings_gdf.loc[bid_j, 'geometry']
        distance = geom_i.distance(geom_j)
        
        matrix.loc[bid_i, bid_j] = distance
        matrix.loc[bid_j, bid_i] = distance  # 对称
        
    return matrix
```

### 3.2 EdgeConvLayer设计

#### 3.2.1 距离感知注意力机制

传统GAT的注意力计算只考虑节点特征：
```
α_ij = softmax(LeakyReLU(a^T [Wh_i || Wh_j]))
```

我们的EdgeConvLayer加入边特征（距离）：
```
α_ij = softmax(LeakyReLU(a^T [Wh_i || Wh_j]) + edge_gate(distance))
```

#### 3.2.2 实现细节

```python
class EdgeConvLayer(nn.Module):
    """
    距离感知的图注意力层
    
    特点：
    1. 共享线性变换（标准GAT设计）
    2. 分离计算的注意力机制（高效）
    3. 可选的边特征门控
    """
    
    def __init__(self, in_channels, out_channels, heads=8, 
                 edge_dim=1, use_edge_features=False):
        super().__init__()
        
        # 共享线性变换（关键：所有节点共用一个W）
        self.lin = nn.Linear(in_channels, heads * out_channels, bias=False)
        
        # 注意力参数（维度 = 2 * out_channels）
        self.att = nn.Parameter(torch.Tensor(1, heads, 2 * out_channels))
        
        # 可选：边特征门控
        if use_edge_features and edge_dim > 0:
            self.edge_gate = nn.Sequential(
                nn.Linear(edge_dim, heads * out_channels),
                nn.Sigmoid()
            )
    
    def forward(self, x, edge_index, edge_attr=None):
        # 1. 添加自环
        edge_index, edge_attr = add_self_loops(edge_index, edge_attr)
        
        # 2. 线性变换
        x = self.lin(x)  # (N, heads * out_channels)
        x = x.view(-1, self.heads, self.out_channels)  # (N, heads, out_channels)
        
        # 3. 计算注意力（分离计算方式）
        att_src = self.att[:, :, :self.out_channels]
        att_dst = self.att[:, :, self.out_channels:]
        
        alpha_src = (x * att_src).sum(dim=-1)  # (N, heads)
        alpha_dst = (x * att_dst).sum(dim=-1)  # (N, heads)
        
        row, col = edge_index
        alpha = alpha_src[row] + alpha_dst[col]  # (E, heads)
        alpha = F.leaky_relu(alpha, self.negative_slope)
        
        # 4. Softmax归一化（按目标节点）
        alpha = self._softmax(alpha, col, num_nodes)
        
        # 5. 可选：边特征门控
        if edge_attr is not None and self.edge_gate is not None:
            gate = self.edge_gate(edge_attr)  # (E, heads * out_channels)
            gate = gate.view(-1, self.heads, self.out_channels)
        
        # 6. 消息聚合
        out = self._aggregate(x[col], alpha, row)
        
        return out
```

#### 3.2.3 与标准GAT的对比

| 特性 | 标准GAT | 我们的EdgeConvLayer |
|------|---------|-------------------|
| 线性变换 | 单个共享W | 单个共享W ✓ |
| 注意力维度 | 2×F | 2×F ✓ |
| 边特征 | 不支持 | 可选支持 |
| 计算方式 | 分离计算 | 分离计算 ✓ |
| 多头支持 | 显式多层 | 单层多头 |

### 3.3 GAT模型架构

```python
class GAT(nn.Module):
    """
    多层图注意力网络
    
    架构：
    Input → [EdgeConvLayer + ELU + Dropout] × (L-1) → EdgeConvLayer → Output
    """
    
    def __init__(self, in_features, hidden_dim, num_classes, 
                 num_layers=3, num_heads=8, dropout=0.6):
        super().__init__()
        
        self.convs = nn.ModuleList()
        
        # 第一层：in_features → hidden_dim
        self.convs.append(EdgeConvLayer(
            in_features, hidden_dim, heads=num_heads
        ))
        
        # 中间层：hidden_dim * num_heads → hidden_dim
        for _ in range(num_layers - 2):
            self.convs.append(EdgeConvLayer(
                hidden_dim * num_heads, hidden_dim, heads=num_heads
            ))
        
        # 输出层：hidden_dim * num_heads → num_classes（单头）
        self.convs.append(EdgeConvLayer(
            hidden_dim * num_heads, num_classes, heads=1
        ))
    
    def forward(self, x, edge_index, edge_attr=None):
        x = F.dropout(x, p=self.dropout, training=self.training)
        
        for conv in self.convs[:-1]:
            x = conv(x, edge_index, edge_attr)
            x = F.elu(x)
            x = F.dropout(x, p=self.dropout, training=self.training)
        
        # 保存嵌入（倒数第二层输出）
        embeddings = x
        
        # 输出层
        logits = self.convs[-1](x, edge_index, edge_attr)
        
        return logits, embeddings
```

### 3.4 LCZ相似度损失函数

#### 3.4.1 设计动机

LCZ类别之间存在语义关系：
- LCZ1（紧凑高层）与LCZ2（紧凑中层）相似
- LCZ1与LCZ9（稀疏建筑）差异很大

传统交叉熵损失将所有错误等同对待，而相似度损失考虑类别关系。

#### 3.4.2 LCZ相似度矩阵

```python
def create_lcz_similarity_matrix():
    """
    9×9 LCZ类别相似度矩阵
    
    设计原则：
    - 同组内相似度高（0.7-0.9）：LCZ1-3, LCZ4-6, LCZ7-9
    - 相邻高度相似度中等（0.5-0.7）
    - 紧凑vs开敞差异明显（~0.5）
    """
    similarity = torch.tensor([
        #     LCZ1  LCZ2  LCZ3  LCZ4  LCZ5  LCZ6  LCZ7  LCZ8  LCZ9
        [1.00, 0.85, 0.65, 0.50, 0.40, 0.30, 0.20, 0.15, 0.10],  # LCZ1
        [0.85, 1.00, 0.85, 0.60, 0.50, 0.40, 0.25, 0.20, 0.15],  # LCZ2
        [0.65, 0.85, 1.00, 0.55, 0.65, 0.55, 0.35, 0.30, 0.25],  # LCZ3
        [0.50, 0.60, 0.55, 1.00, 0.85, 0.65, 0.45, 0.35, 0.30],  # LCZ4
        [0.40, 0.50, 0.65, 0.85, 1.00, 0.85, 0.55, 0.45, 0.40],  # LCZ5
        [0.30, 0.40, 0.55, 0.65, 0.85, 1.00, 0.65, 0.60, 0.50],  # LCZ6
        [0.20, 0.25, 0.35, 0.45, 0.55, 0.65, 1.00, 0.75, 0.70],  # LCZ7
        [0.15, 0.20, 0.30, 0.35, 0.45, 0.60, 0.75, 1.00, 0.80],  # LCZ8
```

#### 3.4.3 软标签生成

```python
class SimilarityAwareCrossEntropyLoss(nn.Module):
    """
    相似度感知的交叉熵损失
    
    将硬标签转换为软标签：
    soft_label = (1-temp) × one_hot + temp × similarity[target]
    """
    
    def __init__(self, similarity_matrix, temperature=0.1):
        super().__init__()
        self.similarity = similarity_matrix
        self.temperature = temperature
    
    def forward(self, logits, targets):
        # 生成软标签
        one_hot = F.one_hot(targets, num_classes=self.num_classes)
        similarity_row = self.similarity[targets]
        
        soft_labels = (1 - self.temperature) * one_hot + \
                      self.temperature * similarity_row
        
        # 计算交叉熵
        log_probs = F.log_softmax(logits, dim=-1)
        loss = -torch.sum(soft_labels * log_probs, dim=-1)
        
        return loss.mean()
```

## 4. 谱聚类管道设计

### 4.1 完整管道流程

```python
def perform_spectral_clustering_pipeline(
    embeddings, features, adjacency_matrix, gat_labels, gat_logits
):
    """
    完整的谱聚类管道
    
    流程：
    1. 计算亲和矩阵
    2. 识别子连通分量
    3. 对每个分量独立聚类
    4. 置信度加权投票
    5. 过滤小聚类
    """
    
    # 1. 计算亲和矩阵
    affinity = compute_affinity_matrix(
        embeddings, features, adjacency_matrix,
        embedding_weight=0.6,
        feature_weight=0.2,
        distance_weight=0.2
    )
    
    # 2. 识别子连通分量（hop约束可能断开图）
    sub_component_labels, num_sub_components = connected_components(affinity)
    
    # 3. 对每个分量独立聚类
    all_clusters = np.zeros(num_nodes)
    cluster_offset = 0
    
    for comp_id in range(num_sub_components):
        comp_mask = (sub_component_labels == comp_id)
        comp_size = comp_mask.sum()
        
        if comp_size >= min_cluster_size:
            # 估计聚类数
            n_clusters = estimate_optimal_clusters(affinity[comp_mask])
            
            # 执行谱聚类
            comp_clusters = spectral_cluster(affinity[comp_mask], n_clusters)
            
            # 偏移聚类ID
            all_clusters[comp_mask] = comp_clusters + cluster_offset
            cluster_offset += n_clusters
        else:
            # 小分量：直接使用GAT预测
            all_clusters[comp_mask] = -1
    
    # 4. 置信度加权投票
    if use_confidence_weighted_voting:
        cluster_to_label, final_labels = assign_labels_with_confidence(
            all_clusters, gat_labels, gat_logits
        )
    else:
        cluster_to_label, final_labels = assign_labels_to_clusters(
            all_clusters, gat_labels
        )
    
    # 5. 过滤小聚类
    filtered_mapping, final_labels, stats, cleaned_clusters = filter_small_clusters(
        all_clusters, cluster_to_label, gat_labels, min_cluster_size
    )
    
    return cleaned_clusters, final_labels, filtered_mapping, affinity, stats
```

### 4.2 亲和矩阵设计

```python
def compute_affinity_matrix(embeddings, features, adjacency_matrix,
                            embedding_weight, feature_weight, distance_weight):
    """
    组合三种相似度源的亲和矩阵
    """
    # 获取邻接掩码（只对相邻节点计算相似度）
    adjacency_mask = adjacency_matrix.values > 0
    np.fill_diagonal(adjacency_mask, True)
    
    # 1. 嵌入相似度
    embedding_sim = cosine_similarity(embeddings)
    embedding_sim = (embedding_sim + 1) / 2  # 归一化到[0,1]
    embedding_sim[~adjacency_mask] = 0  # 只保留相邻节点
    
    # 2. 特征相似度
    feature_sim = cosine_similarity(features)
    feature_sim = (feature_sim + 1) / 2
    feature_sim[~adjacency_mask] = 0
    
    # 3. 距离亲和度（指数衰减）
    distance_matrix = adjacency_matrix.values
    distance_affinity = np.exp(-distance_matrix / distance_scale)
    np.fill_diagonal(distance_affinity, 1.0)
    distance_affinity[distance_matrix == 0] = 0
    
    # 4. 加权组合
    affinity = (embedding_weight * embedding_sim +
                feature_weight * feature_sim +
                distance_weight * distance_affinity)
    
    # 对称化
    affinity = (affinity + affinity.T) / 2
    np.fill_diagonal(affinity, 1.0)
    
    return affinity
```

### 4.3 聚类数自动估计

```python
def estimate_optimal_clusters(affinity_matrix, oversample_factor=0.8):
    """
    使用特征值间隙法估计最优聚类数
    
    方法：
    1. 计算拉普拉斯矩阵的特征值
    2. 找到最大特征值间隙
    3. 间隙位置+1即为聚类数
    4. 可选过采样（更细粒度）
    """
    # 计算归一化拉普拉斯
    degree = affinity_matrix.sum(axis=1)
    D = np.diag(degree)
    L = D - affinity_matrix
    
    # 特征值分解
    eigenvalues, _ = eigh(L)
    eigenvalues = np.sort(eigenvalues)
    
    # 找特征值间隙
    eigengaps = np.diff(eigenvalues[:max_clusters])
    k_base = np.argmax(eigengaps) + 1
    
    # 过采样
    k_final = int(k_base * oversample_factor)
    k_final = max(1, min(k_final, max_clusters))
    
    return k_final
```

### 4.4 连通分量处理

```python
def get_connected_components_from_adjacency(adjacency_matrix, building_ids):
    """
    从邻接矩阵识别连通分量
    
    重要：使用原始Voronoi邻接而非PyG的edge_index
    因为edge_index可能包含多跳连接
    """
    # 创建二值邻接
    binary_adj = (adjacency_matrix.values > 0).astype(int)
    sparse_adj = csr_matrix(binary_adj)
    
    # 识别连通分量
    n_components, labels = connected_components(
        csgraph=sparse_adj,
        directed=False,
        return_labels=True
    )
    
    return labels, n_components
```

```
       │ 任务队列
       ├──────────┬──────────┬──────────┐
       ▼          ▼          ▼          ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ Worker 1 │ │ Worker 2 │ │ Worker 3 │ │ Worker N │
│ (Rank 1) │ │ (Rank 2) │ │ (Rank 3) │ │ (Rank N) │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

### 5.2 动态负载均衡

```python
def master_task_distributor(comm, size, districts, config):
    """
    Master进程：动态任务分配
    
    特点：
    1. 按区县面积排序（小区县优先）
    2. 跳过已处理的区县
    3. Worker完成后立即分配新任务
    """
    task_idx = 0
    completed = 0
    
    # 初始分配：每个Worker一个任务
    for worker_rank in range(1, size):
        if task_idx < num_tasks:
            comm.send(task_idx, dest=worker_rank, tag=TAG_TASK)
            task_idx += 1
        else:
            comm.send(-1, dest=worker_rank, tag=TAG_TERMINATE)
    
    # 处理完成请求
    while completed < num_tasks:
        status = MPI.Status()
        comm.recv(source=MPI.ANY_SOURCE, tag=TAG_REQUEST, status=status)
        worker = status.Get_source()
        completed += 1
        
        # 分配新任务或终止
        if task_idx < num_tasks:
            comm.send(task_idx, dest=worker, tag=TAG_TASK)
            task_idx += 1
        else:
            comm.send(-1, dest=worker, tag=TAG_TERMINATE)
```
